Light controls

Power, color, and brightness

Controls show selected values, not readings from the lights. Connecting does not automatically change them.

Color sequences

Hold each color, then fade to the next. Repeat also fades the last color back to the first.

Sequence editor and saved sequences

Holiday presets repeat continuously. Most hold each color for 5 seconds, then fade for 5 seconds; Thanksgiving uses 8 / 6 seconds and New Year's uses 3 / 3 seconds. Load a preset to see or customize its colors and timing; your saved sequences are not changed. Colors may look different on your lights: adjust the color pickers and save a custom version.

    Connection help & command log

    Use Chrome or Edge at http://lotuslantern.localhost:49173 (the default address). Enable Bluetooth on your Mac and allow Chrome access in System Settings > Privacy & Security > Bluetooth.

    Select the lights in Chrome's chooser. Only device names starting with BLEDOM or ELK-BLEDOM are shown (case-sensitive). Chrome supports prefix filtering, not arbitrary substring matching. Only select a device you own. If it does not appear, close the phone app, power-cycle the controller, and try again. Controllers with other names or no advertised name are excluded.

    If service discovery fails or the lights ignore commands, this hardware may use a different protocol. Share the device name and the error below to help identify it. Sequences run in this browser; built-in controller effects and scheduling are not included until the controller model is confirmed.

    Close LotusLanternX and any browser Bluetooth connections before connecting Python. Allow Bluetooth for the Python interpreter or terminal in macOS Privacy & Security settings. Only the selected BLEDOM device is used; being out of range is normal. Connection errors appear in the service status; the command log below is for this page only. Saved sequences and playback settings are in ~/Library/Application Support/LotusLantern/state.json. The service is local to this Mac, not connected to the public website.
